  minCyc     = admitted FIFO-B entries; 1 activation/cycle with no stalls
  cmpCyc     = streaming cycles = minCyc + fetch-stall beats
  latency    = end-to-end: cmpCyc + weight-load + arm + drain
  speedup    = roofline cmpCyc / this case's cmpCyc
  GOPS/s     = rate over streaming cycles, 1 MAC = 2 ops
  multUtil%  = MACs / (cmpCyc x NUM_MULTS)   <- the headline metric

               (union-gated stream: lanes whose kernel lacks this PID)
  stall%     = lane-slots lost to whole-PE fetch-stall beats (SKIP)
               multUtil + idle + stall = 100 by construction
  macs/act   = useful MACs per admitted activation (broadcast efficiency)
  inBits/mac = input-side transfer (FIFO-B entries + weight fills) per MAC
